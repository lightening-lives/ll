## Design Specificity Verdict

**Authored — decisively.** Strip the wordmark and no other company could use this page. The load-bearing objects come off the actual bench: an SBS 8x12 plate with a deliberately partial run, a Code 128 barcode genuinely encoded from the specimen ID rather than hatched with a gradient, a dried spot at chroma 0.165–0.205 because a brown spot is what a *failed* sample looks like, and a variant ladder where geometry rather than colour carries the class of mutation. The 10^0 -> 10^-3 -> 10^-9 -> 10^0 scale rail is an argument about what the product is.

Specificity thins to zero in exactly one layer: the evidence. `#reachGrid` renders `0 / 0 / 0 / 0`, the accreditation chip reads `NABL M(EL)T-0000`, two of four performance stats carry `n = 0,000` — while a counter 400px above animates to `1,24,860 samples reported to date`.

**Deterministic scan:** unavailable (`scripts/detector/` and `cli/engine/` both absent). Substituted: composited-ground contrast math at 14 scroll depths, full computed-style type inventory at 1440 and 390, element-edge overflow scan at five widths, 77-control accessible-name audit, network and console capture.

## What's Working

1. **The small-type role scale is a semantic rule, not a size rule.** Splitting by voice — mono means a machine reads it back, sans means a person reads it — fixed a real failure where "Sir J.C. Bose Fellowship" rendered as an 11px uppercase part number. B verified 7 of 10 roles match their documented values exactly, tracking included.
2. **The assay markers are projected, not embedded.** Real `<button>`s parked at each locus's projected centre give a still target on a turning object, and get Tab, Enter, Escape and screen readers for free. All seven verified at 32x32px with full `aria-label`s.
3. **Reduced motion is designed, not disabled.** `.helix` is deliberately exempt from the `transform: none` reset, because nulling it removes the camera rather than the animation. `prefers-contrast: more` holds illumination LOW — counter-intuitive and correct.

## Priority Issues

### [P0] The evidence layer renders as zeros, and contradicts itself
**Why it matters.** All three audiences are evaluating legitimacy in exactly this region. "1,24,860 samples" and "0 collection points" on one scroll is not an unfinished field, it is a contradiction, and a procurement officer resolves contradictions against the supplier. `NABL M(EL)T-0000` is worse than no chip — a malformed accreditation number is disqualifying on sight in Indian diagnostics.
**Fix.** Skip any `reach.stats` entry whose value is falsy or `'0'` and render the section as the five real states alone (`src/content.js:596`). Drop `'NABL M(EL)T-0000'` (`:305`). Replace `'n = 0,000'` with `'validation study in progress'` (`:300-301`). Also: `.build-note { display:none }` (`src/input.css:2135`) hides the honest "Placeholder figures" disclaimer behind a keypress.
**Command:** `clarify`

### [P0] The primary action does not work and has no validation
**Why it matters.** Every CTA funnels to `#contact`. The page spends 20 screens building trust, then the door is nailed shut with a red line that reads as a bug.
**Fix.** Remove `novalidate` (`index.html:389`), add `checkValidity()` + `aria-invalid` + `aria-describedby` + focus-first-error in `src/scene.js:385`. Until the endpoint exists, make the honest path the designed path: a `mailto:` with pre-filled subject styled as primary.
**Command:** `harden`

### [P0] A dev tool ships in production, and it changes the rendered palette
**Why it matters.** `preview/ground-switcher.js` is loaded from `index.html:472` and injects `#gs-host` at `z-index: 2147483000`. `preview/ground-switcher.js:81` sets `DEFAULT_ID = 'slate'`, so the live page renders `void` at 20% not 13% and `mute` at 69% not 64% — not DESIGN.md's committed token table. The lift genuinely helps the mid-range-Android-in-daylight constraint, but DESIGN.md's central argument is that the page opens at ~6% illumination.
**Fix.** Decide which is the committed world, then make one of them true: either update DESIGN.md's token table and opening argument to slate, or change the default back to darkfield. Either way, gate the switcher out of the production bundle.
**Command:** `harden`

### [P1] The new 450 base weight leaks onto display type
**Why it matters.** Both assessments found this independently. `p, li, dd { font-weight: 450 }` reaches `<p>` elements carrying Fraunces display type: `.story__pull` renders 40px/450 and `#inhHeadline` 29.6px/450, while every real `h1/h2/h3` renders 400. That directly undoes the reason `h1,h2,h3 { font-weight: 400 }` exists. It also creates a same-size-two-weights collision: `.vidx__what` 12.5px/450 beside `.vidx__note` 12.5px/400, both mute, both Plex Sans, both inside `#variantIndex`. Separately, `claim` is documented Sans 600/15px but implemented at 14px in `.pillar__t`, `.story__t` and `.team-name`.
**Fix.** Make the compensation opt-in by role, not by element: `.prose { font-weight: 450 }` at the six call sites the pass touched, dropping the `p, li, dd` selector. Set `.pillar__t`, `.story__t`, `.team-name` to `.9375rem`. Add `font-weight: 400` to `.vidx__what`.
**Command:** `typeset`
